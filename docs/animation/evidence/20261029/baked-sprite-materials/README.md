# Actual baked-sprite GPU framebuffer proof

Generated by `tools/animation/check_baked_sprite_gpu.cjs` against the published
C# Enemy Lab and current source JS/material overlay. 320/390 CSS px, touch/DPR3
desktop emulation; **not physical iOS/Android performance or final art acceptance**.

PNG files are actual native GPU world framebuffers, vertically oriented for
inspection without resampling. `neutral-*` uses the explicitly declared existing
developer inspection light; `zero-light` disables all world light and emission.
The same shared LightingEngine, C# state, atlas frame, source maps and anchor are
used throughout. There is no synthetic replacement scene or runtime character
mesh. The unfiltered albedo/normal views are diagnostics, not night gameplay.

Both sizes pass: actual baked-sprite actor/resources present, no browser errors,
distinct albedo/normal output, every zero-light RGB channel exactly zero, exact
paused lit restoration. Visible cutout shadows are preserved; this does not
establish source depth/volume or final Hunt occlusion/mobile acceptance.
See `gpu-contract.json` for hashes, light settings and renderer diagnostics.
