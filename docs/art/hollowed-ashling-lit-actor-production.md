# Hollowed / Ashling — source-derived lit-actor materials

**Branch:** `feat/actor-lit-hollowed-ashling`, child of the in-progress GPU engine [PR #332](https://github.com/pjotrcasteel/Wyrmforge/pull/332). This document reports authored assets, not owner visual signoff or a production renderer cutover. [Canonical animation rules](../canon/art-and-animation.md).

## Immutable approved assets and new material passes

| Actor | Walk | Attack | Death | Total |
| --- | ---: | ---: | ---: | ---: |
| Hollowed | 8 × 16 | 8 × 16 | 8 × 24 | 448 |
| Ashling | 8 × 16 | 8 × 22 | 8 × 28 | 528 |

Source rigs, sampled per-frame posed triangle meshes, approved color PNGs, feet anchors, world sizes, palettes and animation profiles are unchanged. The original **walk normal maps already exported on PR #332** remain exact byte-for-byte inputs; they are validated, never regenerated by this task.

`tools/art/export-lit-actor-materials.py` consumes the **original deformed 3D surface positions, mesh triangles, source-camera matrix and eight authored orientations**. It z-buffers each pose into the exact existing atlas frame grid and encodes its camera-space surface normals into an RGBA atlas. Its non-color 16-bit depth map contains source-camera normalized device Z, with zero meaning no mesh. It exports a synchronously sampled mesh-alpha caster atlas. This is real surface-derived data, not a normal map inferred from RGB. Its mesh-pixel coverage is checked against approved alpha, and original source pose hashes are checked where supplied.

`lit-material-manifest.json` per creature specifies original color, normal, camera depth, caster atlas, exact clip cell/frame/pivot/world size, authoring provenance, data hashes, roughness/specular and independent cast/receive flags. `lighting/actor-materials.js` validates the bundle and reuses **the existing `spriteFrame` result** for *every* material pass. No material clock, sprite-direction strategy or creature-specific light rule is introduced.

## Important honest limitations

- **Caster quality:** the caster image is a *screen-space source-mesh silhouette only*. The current G1 renderer's standard sprite plane can cast alpha-clipped shadows, but its existing shadow pass still samples the COLOR atlas, not the independent caster atlas. Genuine posed-mesh volumetric shadows or self-occlusion are **not implemented** by these asset passes. PR #332 owns any engine-side support; this PR does not modify that engine. Fire VFX pixels are excluded from geometry casters where source mesh has no surface.
- **Depth:** the saved `I;16` atlas is camera-relative normalized device depth, not metrically calibrated height or a drawable 3D occluder. Consumers must not treat it as world-height without deliberate conversion/validation.
- **Light-neutral albedo:** approved color sheets retain their historical baked palette/shading. Dynamic lights can shade them, but true light-neutral source colour must be visually assessed before claiming physically clean lighting; do not bleach/recolor approved sprites by algorithm.
- **Ashling emission:** geometry-derived **eye-only** emissive-mask atlases now exist for walk, attack and death, rasterized from original source-bound vertex weights and extinguished by authored death frame 13. The material manifest records source checksums and the portable adapter exposes their paths. **PR #332 does not yet bind them to a GPU emissive-map channel**, so `emissive=null` remains correct until engine integration and artistic review. The Ashling claw/ember VFX emission has not yet been extracted as a separately validated pass. No full-bright bypass is claimed.
- **Idle and hurt:** neither character has independently approved authored `idle` or `hurt` clips in its current runtime manifest. Existing stationary walk-pose presentation and shader hit-flash are legacy fallbacks, **not completed art animations**.
- **Movement direction from owner:** Hollowed should feel closer to fast, feral *World War Z* (2013) movie infected than a passive shambler: real acceleration, unstable upper-body lean, sudden claw reaches, forward momentum and grounded recoveries. Ashling stays a distinct low-running, weighty beast with its own launched attack. New locomotion/hurt rigs and authored exports need review; accepted base clips are untouched. Do not speed up existing footage or stretch frames and call it a new animation.

## Reproducible validation

Run from the repository root:

```sh
python -m pip install "numpy<2.4" Pillow numba
python tools/art/export-lit-actor-materials.py
python tools/art/validate-lit-actor-materials.py
node --test tests/javascript/actor-lit-materials.test.mjs
```

GitHub Action `actor-lit-materials.yml` regenerates the binary passes on **this task branch only**, validates them, and commits the result without touching PR #332. Validator checks 976 authored source frames, exact clip dimensions, direction count, original alpha containment, transparent frame borders, caster/depth synchronization, original albedo checksums, source-pose checksums and stored output hashes.

The independent `actor-review-scene.js` passes all authored walk/attack/death samples through the SAME `LightingEngine` implementation as #332, without modifying its shaders. `ActorLitSpriteBrowserTests` exercises every frame at 320×568 and 390×844 and captures full Hunt-scale, magnified, light-moved, shadow-disabled and zero-light screenshots. Such browser evidence proves the *isolated shared-GPU asset path*, **not** production Hunt integration or real iPhone/Android performance.
