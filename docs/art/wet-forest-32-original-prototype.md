# Original 32×32 Wet Forest prototype — AR4 source study (30 October 2026)

**Status: source-authored visual candidate; not approved; not connected to live Hunts.**
The canonical AR0–AR7 milestone/approval contract is [the roadmap](../canon/roadmap.md#world-authored-arenas-and-groundmaterial-fidelity--ar0ar7-owner-decision-29-october-2026-locked). This document is an implementation record, not a replacement architecture.

## Intent and rights

Seven downloadable example packs were supplied as visual references to learn techniques: clean 32×32 pixel clustering, tile variation, organic edge treatments, small silhouettes, layered vegetation and readable material vocabulary. **Do not import, trace, recolor, or repackage any pixels, animations or textures from those packs.** They are not game dependencies. Pack terms vary even when files are described as free; preserve each original license for future reference, and do not submit third-party reference artwork to AI image tools where prohibited. This implementation generates its pixels from independent authored JavaScript primitives and color palettes.

Gothic Diablo-like atmosphere and grounded 2.5D presentation remain locked. Dark forest floor and muted highlights are intentional; magic illumination belongs to the existing G0–G5 shared GPU renderer.

## First checkpoint: WF32-P0

The opt-in source module is `tools/art/prototypes/wet-forest-32.mjs`, built on the repository's existing `Bitmap`, `rng`, `packAtlas` and PNG encoder. It produces exactly 16 original native 32×32 frames:

- Three variants each: forest soil, wet grass, mud and weathered stone (12 total).
- Grass/mud boundary studies: one vertical and one horizontal (2). These are **art-only** demonstrations, not approved production blending logic; AR3 weight maps remain authoritative.
- Transparent grounded details: root and fern (2).

The module imports without changing the game. It creates PNGs only when run as a command:

```sh
node tools/art/prototypes/wet-forest-32.mjs
node --test tests/javascript/wet-forest-32.test.mjs
```

Default generated output: `docs/art/previews/wet-forest-32/atlas.png`, `contact-4x.png` and `manifest.json`. The manifest contains per-frame atlas source rectangles, anchor positions, deterministic ordering, pixel dimensions, and original-art provenance. Artifacts generated by this standalone review CLI are **not** included in the normal live `build-art.mjs --check` output and need not change existing versioned runtime atlases. Review images represent **source art, not actual gameplay screenshots**.

## Acceptance gates and upcoming work

1. **P0 original study:** source authored, export reproducible, tests green, art contact available. This is a technical checkpoint only.
2. **P1 art review:** owner approves or requests revisions to actual 32px color ramps, silhouette texture vocabulary, scale and variation. Inspect zoomed and native 320/390px compositions. No reference-pack pixels.
3. **P2 material interfaces:** after AR3 geographic/material-field approval, add meaningful material IDs and controlled variation mapping into the existing shared G renderer, not a second renderer or independent JS geographic recipe. Lighting-neutral albedo, optional normal/roughness, and repeat resistance need separate acceptance.
4. **P3 in-Hunt pilot:** same C# site seed and exact map routes in flat-color versus textured mode, with camera motion, real actor feet/occlusion, fireball and Hollowed lighting response, and measured mobile performance.
5. **P4 AR4 owner material approval:** only then scale production toward 84-piece Wet Forest material library and the AR5 rooted ecology stage.
