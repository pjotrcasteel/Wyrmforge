# 0.0.58 — Fun Ugly Gate

This milestone validates whether WyrmForge is mechanically strong enough to justify serious art production.

## Pass criteria

A run should remain understandable and engaging with placeholder visuals, and repeated runs should produce meaningfully different builds through spells, upgrades, relics, resonance, Wyrm influence, route choices, Essence risk, and Forge unlocks.

Use the end-of-run report to compare runs by build identity, spell ranks, upgrades, synergies, relics, resonance, route progress, Wyrms slain, Essence secured, and run seed.

When a run exposes an interesting or broken sequence, use **Replay same seed** to reproduce the same run RNG stream and compare different player choices.

## Questions to answer during playtesting

- Did the run form a recognizable build identity?
- Did map choices materially influence that build?
- Did rewards create interesting decisions rather than obvious picks?
- Did enemies and Wyrm pressure make the build matter?
- Did descending feel meaningfully riskier than extracting?
- Did a second run feel mechanically different from the first?
- Would the run still be enjoyable if all art remained placeholder quality?

Serious art production should begin only after the answer to the final question is consistently yes.
