# Gothic forest kit — provenance

`src/Wyrmforge.Presentation.Web/wwwroot/art/environment/forest/forest-kit.{png,json}` is generated by
[`tools/art/build_gothic_forest_kit.py`](../../../../tools/art/build_gothic_forest_kit.py) from **Pixel Crawler — Free Pack 2.11** by **Anokolisa**
(Patreon: https://www.patreon.com/Anokolisa).

Terms shipped with the pack (`Terms.txt`): credit is not required but appreciated; the assets may be used in commercial products. Credit is
given here and should appear in the game's credits screen.

What we changed: the silhouettes (conifers, oaks, tall pines, bare trees, stumps) are cut from the pack and every pixel is recoloured into
WyrmForge's cold, dark palette in four Wyrm Influence states — live, dry, dead and charred (embers on charred wood). The pack itself is not
committed; to regenerate, extract it and run

    python tools/art/build_gothic_forest_kit.py "<extracted>/Pixel Crawler - Free Pack"

The sprites are drawn at 1 source pixel = 1 world pixel (1 m = 32 px).
