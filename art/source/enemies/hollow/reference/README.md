# Hollowed reference motion (unapproved)

Original source: Carnegie Mellon University Graphics Lab Motion Capture Database,
Subject 09, Motion 01 (run), captured at 120 fps. 
Official rights notice: https://mocap.cs.cmu.edu/ ("free for all uses").
BVH conversion: Bruce Hahne, 2010, mirrored by
https://github.com/una-dinosauria/cmu-mocap/blob/master/data/009/09_01.bvh .

The 116 KB BVH source file is preserved without interpolation, hand-editing,
recoloring or changing its initial source samples. It is reference data only.
All processed Hollowed poses are independently retargeted to the *existing*
editable hollow-rigged.blend from rigged-pixel-v3, via
`tools/sprite-lab/build-hollow-mocap-run.py`.

The existing approved Hollowed and Ashling 8-direction texture atlases and
lighting engine #332 normal maps MUST NOT be overwritten with the result.
The 16-frame GIF, four diagnostic azimuths and saved .blend constitute
unapproved animation reference/prototyping until artistic sign-off.
